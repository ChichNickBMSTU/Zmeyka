🐍 Snake Game
A classic Snake game with two types of apples and intuitive controls.

📋 Description:
Control the snake, collect apples, and grow as long as you can! But be careful — with every golden apple, the snake gets faster.

🎮 Controls:
Key	                       Action
⬆️ ⬇️ ⬅️ ➡️	         Move the snake
Q	                      Quit the game
C	                     Restart the game

🍎 Apple Types:
Apple	                      Effect
🟡              Golden apple	The snake grows longer and speeds up
🔴                 Red apple	The snake only grows longer

🕹️ How to Play:
Launch the game.
Control the snake using the arrow keys.
Collect apples to score as many points as possible.
Try not to crash into the walls or your own tail.
Press C to restart the game at any time.
Press Q to quit the game.

⚙️ Features:
🐍 Smooth snake controls
🟡 Golden apples speed up the game — the more you eat, the harder it gets!
🔴 Red apples simply increase the snake's length
🔄 Quick restart with the C key
🚪 Instant quit with the Q key

🏆 Goal of the Game:
Score as many points as possible without crashing into the walls or your own tail. Remember: the more golden apples you eat, the faster you'll need to react!

💡 Tips:
Don't rush straight for the golden apples — at high speed, the snake is harder to control.
Plan your route ahead so you don't corner yourself.

Have fun playing! 🎉


🐍 Игра «Змейка»
Классическая игра «Змейка» с двумя типами яблок и удобным управлением.

📋 Описание:
Управляйте змейкой, собирайте яблоки и растите как можно дольше! Но будьте осторожны — с каждым золотым яблоком змейка становится быстрее.

🎮 Управление:

Клавиша	             Действие
⬆️ ⬇️ ⬅️ ➡️	    Движение змейки
Q	                 Выход из игры
C	                Начать игру заново

🍎 Типы яблок
Яблоко	                  Эффект
🟡             Золотое яблоко	Змейка удлиняется и ускоряется
🔴             Красное яблоко	Змейка только удлиняется

🕹️ Как играть
Запустите игру.

Управляйте змейкой с помощью стрелок.
Собирайте яблоки, чтобы набрать как можно больше очков.
Старайтесь не врезаться в стены и в собственный хвост.
Нажмите C, чтобы перезапустить игру в любой момент.
Нажмите Q, чтобы выйти из игры.

⚙️ Особенности:
🐍 Плавное управление змейкой
🟡 Золотые яблоки ускоряют игру — чем больше, тем сложнее!
🔴 Красные яблоки просто увеличивают длину
🔄 Быстрый перезапуск клавишей C
🚪 Мгновенный выход клавишей Q

🏆 Цель игры
Набрать максимальное количество очков, не врезавшись в стены или собственный хвост. Помните: чем больше золотых яблок вы съедите, тем быстрее придётся реагировать!

💡 Советы
Не гонитесь сразу за золотыми яблоками — на высокой скорости сложнее контролировать змейку.
Планируйте маршрут заранее, чтобы не загнать себя в угол.


Приятной игры! 🎉
